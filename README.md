# astrbot_plugin_limit_use

一个 **AstrBot** 插件，为 QQ 用户设置对话次数额度，次数用完后需签到补充；支持按余额百分比参与「模拟行情投资」。

## 功能

- ✅ **次数限制** — 每个用户与 Bot 对话时，每次消耗 1 次额度
- ✅ **自动拦截** — 次数用完后自动回复指定内容，并阻止继续对话
- ✅ **每日签到** — 发送 `/签到` 领取每日奖励次数（固定范围或自定义权重两种模式）
- ✅ **投资模式** — 发送 `/投资` 用当前余额的百分比参与模拟行情，行情按「日期+币种」确定性随机，每日 1 次（与签到共享）
- ✅ **余额查询** — 发送 `/我的余额` 查看剩余次数
- ✅ **帮助指令** — 发送 `/帮助` 查看所有可用指令（图片卡片，失败自动回落文本）
- ✅ **管理员免限** — 配置管理员 QQ 号列表，不限次数
- ✅ **WebUI 管理** — 在 AstrBot 管理面板的插件详情页中查看/修改用户数据：私聊与群聊分组展示、自动记录最近昵称，并查看今日行情与投资记录（单视图，页内标签切换）

## 指令

| 指令 | 权限 | 说明 |
|:---:|:---:|:---|
| `/帮助` | 所有人 | 显示所有可用指令 |
| `/签到` | 所有人 | 每日签到，获取一定量的对话次数（每日限一次） |
| `/我的余额` | 所有人 | 查看当前剩余的对话次数 |
| `/投资` | 所有人 | 投资：`/投资 原石 10` 表示用当前余额的 10% 参与当日行情；不带参数时显示今日行情与状态（每日一次，与签到共享） |
| `/查看全部余额` | 管理员 | 以「昵称（QQ号）：剩余N」列出余额：**群聊中只统计本群用户**，私聊统计全部用户；渲染为图片卡片，失败回落文本（`/帮助` 中不显示） |

### 投资模式说明

- 指令格式：`/投资 <币种> <百分比>`，例如 `/投资 原石 10` 表示投入当前余额的 10%
- 投入次数 = `max(1, 余额 × 百分比 ÷ 100)`（向下取整，且不超过当前余额）
- 盈亏 = 投入次数 × 当日涨跌幅 − 手续费；新余额 = `max(0, round(当前余额 + 盈亏))`，即最多亏到 0
- 行情由「日期 + 币种」的哈希确定性生成，同一天同一币种结果固定，无法靠重试刷结果
- 签到与投资共享每日一次：今天已签到就不能投资，今天已投资就不能签到
- 旧格式（如 `/投资 原石 做多 10 5x`）会自动忽略方向与杠杆，取第一个 1–100 的整数作为百分比
- `/投资` 与 `/投资 <币种> <百分比>` 都优先渲染浅色卡片图；未配置文转图时自动回落纯文本

## 配置

在 AstrBot WebUI 的插件配置面板中可修改以下项：

| 配置项 | 类型 | 默认值 | 说明 |
|:---|:---:|:---:|:---|
| `default_quota` | int | `5` | 新用户初始对话次数 |
| `daily_bonus_min` | int | `5` | 签到奖励随机范围的最小值 |
| `daily_bonus_max` | int | `5` | 签到奖励随机范围的最大值（与最小值相等则为固定值） |
| `signin_mode` | string | `range` | `range`：按最小-最大范围随机；`weighted`：按 `signin_weights` 权重随机 |
| `signin_weights` | text | `5:1\n3:2\n10:1` | `weighted` 模式的权重配置，每行一组「值:权重」 |
| `limit_reply` | text | `呜呜，你的对话次数已经用完啦...` | 次数用尽时的回复内容 |
| `signin_reply` | text | `签到成功！获得 {bonus} 次对话次数...` | 签到成功回复，可用 `{bonus}` 占位符 |
| `quota_query_reply` | text | `你还有 {quota} 次对话次数哦...` | 余额查询回复，可用 `{quota}` 占位符 |
| `admin_users` | list | `[]` | 免次数限制的管理员 QQ 号列表，如 `["123456", "789012"]` |
| `invest_enabled` | bool | `true` | 是否启用投资模式 |
| `invest_assets` | text | `原石:160\n菲林:100\n水晶:280\n星琼:160` | 可投资币种，每行一组「币种:基准价」；基准价只用于展示现价 |
| `invest_volatility` | float | `3` | 每日最大涨跌幅（%） |
| `invest_fee_percent` | float | `0` | 每笔投资手续费（%），按投入次数收取；`0` 表示免手续费 |
| `invest_history_limit` | int | `200` | 保留的投资记录条数（WebUI 投资记录表） |

> `signin_weights` 每行格式为 `值:权重`，例如 `5:1` 表示获得 5 次对话次数的权重为 1。
> 格式错误的行会被忽略；若整段配置都无法解析，`weighted` 模式会回落到 `daily_bonus_min`～`daily_bonus_max` 范围随机。
>
> `invest_assets` 每行格式为 `币种:基准价`，例如 `原石:160`；币种名称会原样出现在指令与卡片里，
> 基准价只用于计算/展示现价，不影响盈亏比例。格式错误的行会被忽略，全部非法时回落到默认四个币种。

## WebUI 管理页面

安装并启用插件后，在 AstrBot WebUI → 插件详情页 → 「打开页面」进入管理页（目录 `views/manage/`）。
页面顶部用标签在「用户管理 / 行情与投资」之间切换（标签会写入 URL 的 `#users` / `#invest`，刷新后保持）。

**用户管理**：

- 顶部统计栏：用户总数、累积调用、剩余总次数、累积 Token、今日 Token
- 用户列表按聊天窗口分两组，**群聊在上、私聊在下**，每组标题可点击折叠（折叠状态记在浏览器本地）
- 群聊（QQ 号、群昵称、群号）与私聊（QQ 号、最近昵称、最近私聊时间）
- 昵称自动记录：用户每次触发对话、签到、投资或查余额时刷新最近昵称/群名片，无需手工维护
- 剩余次数：直接输入数字，回车或点击别处（失焦）保存；输入非数字会自动还原，同一用户跨组同步
- 每行「删除」按钮：确认后删除该用户的额度、签到、调用统计、Token、投资记录与昵称档案（不可恢复）
- 搜索框按昵称、QQ 号或群号过滤
- 底部「危险操作 → 清空全部数据」：弹窗输入「清空」后确认，一次删除所有用户的全部数据（不可恢复）

**行情与投资**：

- 今日行情卡片：币种名称、现价、基准价、涨跌幅
- 统计栏：投资笔数、参与用户、累计投入、累计盈亏
- 投资记录表：时间、用户、币种、投入比例、投入次数、今日行情、盈亏、手续费、余额变化（只读）

数据全部来自插件 KV 存储，修改后即时生效。

> 说明：AstrBot 侧边栏的「插件页面」默认每个插件只显示第一个视图（扁平模式），
> 所以本插件只提供一个视图、页内用标签切换，避免多个视图在默认 UI 下只能看到其中一个。

## 安装

### 通过 AstrBot 插件市场

1. 打开 AstrBot WebUI
2. 进入「插件管理」
3. 搜索 `astrbot_plugin_limit_use`
4. 点击安装

### 手动安装

```bash
cd AstrBot/data/plugins
git clone https://github.com/XFYX521/astrbot_plugin_limit_use.git
```

然后在 WebUI 中重载插件即可。

## 依赖

- **AstrBot ≥ 4.29.0**（`views/` 插件视图从 4.29.0 起可用；最低版本同时写在 `metadata.yaml` 的 `astrbot_version` 中，低版本会拒绝加载并提示）
- 早于 4.29.0 的 AstrBot 不会渲染本插件的 WebUI 管理页面，请先升级
- 消息平台：QQ（aiocqhttp）
- 可选：AstrBot 的**文转图**（Playwright）用于 `/帮助` 与 `/投资` 的卡片图；未配置时自动回落纯文本，不影响功能

无第三方 Python 依赖，因此没有 `requirements.txt`（该文件是插件三方依赖的 pip 清单，AstrBot 安装插件时会据此安装；只有引入 `aiohttp`、`pyyaml` 这类非标准库时才需要创建）。

## 验收步骤

离线部分：`python -m py_compile main.py`、`python tests/test_plugin_offline.py`。

在真实 AstrBot 中请逐项确认：

1. 重载插件后 WebUI 插件配置页出现 14 个配置项，`signin_weights`、`invest_assets` 默认值均为多行。
2. 普通用户首次对话扣 1 次；额度为 0 时收到 `limit_reply` 且不再调用 LLM。
3. `/签到` 首次获得奖励，同一天再次发送提示已签到；`weighted` 模式下奖励只出现配置过的值。
4. `/我的余额` 正常；管理员在群里发送 `/查看全部余额` 时只列出本群出现过的用户、在私聊发送时列出全部用户，均为图片卡片（失败回落「昵称（QQ号）：剩余N」文本）。
5. `/帮助` 返回浅色卡片图（含插件名与 v2.2.0、不显示管理员指令）；未配置文转图时回落为文本。
6. `/投资` 不带参数返回今日行情图（含余额与今日状态）；`/投资 原石 10` 返回结算卡片（投入为余额的 10%）。
7. 同一天第二次 `/投资` 提示已投资；今天已签到再投资、或今天已投资再签到，都提示共享每日一次。
8. 百分比为 0、101、非数字、币种不存在均有中文提示；余额为 0 时提示先签到。
9. WebUI「用户管理」标签：群聊在上、私聊在下，两组标题可点击折叠；昵称与群号自动出现（无需备注字段）；输入框修改剩余次数后同用户的所有行同步；搜索按昵称/QQ 号/群号生效。
10. WebUI 用户行「删除」按钮：确认后该用户从两张表中消失，切换「行情与投资」其投资记录也被移除。
11. WebUI「行情与投资」标签：今日行情卡片、统计栏与投资记录表能显示刚完成的投资。
12. 浏览器直接访问非法参数（如 `/astrbot_plugin_limit_use/update/<QQ号>/abc`）返回 400 而非 500。

## 版本与发布

- 版本号规则：`x.x.x` —— 第一位大版本号（大改时递增）、第二位小版本号（小功能）、第三位补丁号（修补）；
  版本号唯一来源是 `metadata.yaml` 的 `version`，`versions.json` 与 `VERSIONS.md`
  由 `python scripts/gen_versions.py` 从 `CHANGELOG.md` 和 git 历史生成，**不要手改**。
- 自动更新检测：在 WebUI「插件市场 → 插件源」添加
  `https://raw.githubusercontent.com/XFYX521/astrbot_plugin_limit_use/master/versions.json`，
  再以市场方式安装本插件（已从链接安装的用「更换插件源」绑定到该源）。AstrBot 只对
  `install_method == "market"` 的安装显示「有新版本」，链接安装只会显示「强制重新安装」。
  详见 [VERSIONS.md](VERSIONS.md)。
- 发版流程：改 `metadata.yaml` 版本 + 在 `CHANGELOG.md` 顶部加条目 → 运行生成脚本 →
  提交 → `git tag -a vX.Y.Z -m "vX.Y.Z"` → 推送 `master` 与 tags。
- 若同时维护官方市场记录，`version` 取 `metadata.yaml`，`repo` 填仓库地址，`download_url`
  用 `versions.json` 中该版本的 `zip_url`（依赖已推送的同名 tag）。
